# Тестовые «утечки»

Здесь лежит генератор выдуманных секретов, на которых проверяется, что сканер реально находит каждый класс находок.

```bash
npm run fixtures    # создаёт fixtures/leaks/ (в .gitignore)
npm run scan:demo   # прогон сканера по ним
```

Настоящих ключей в каталоге нет и быть не должно, а сами значения намеренно **не лежат в репозитории целиком**: их собирают из частей `make-leaks.mjs`. Иначе GitHub Secret Scanning видит паттерны в дереве и блокирует пуш, а profilе появляется лишняя тревога.

`npm test` проверяет правила по строкам, а CI гоняет CLI по `fixtures/leaks/`
(`.github/workflows/ci.yml`, job `fixtures`) и требует, чтобы нашлись все ожидаемые правила
и чтобы ни одно значение не попало в отчёт.

При самопроверке репозитория каталог `fixtures/` исключается: `node src/cli.js . --ignore "fixtures/"`.
